# OSPF Configuration Lab

## Objective

Build and verify dynamic routing between routers using Open Shortest Path First (OSPF) in Cisco Packet Tracer.

## Project file

Upload the Packet Tracer project file into this folder as:

`OSPF-Lab.pkt`

## Lab documentation

Add the following details after confirming them in the Packet Tracer topology:

- Network topology and router names
- Router interfaces and IP addressing
- OSPF process ID and area assignments
- Networks advertised into OSPF
- Neighbor adjacency verification
- Routing-table verification
- End-to-end ping tests

## Useful verification commands

Run these on the relevant Cisco IOS routers and record the actual output:

```text
show ip interface brief
show ip ospf neighbor
show ip route ospf
show ip protocols
ping <destination-ip>
```

## Evidence

Add topology and CLI screenshots in this folder. Include a short note explaining what each screenshot demonstrates.
